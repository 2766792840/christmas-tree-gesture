# 共建指南 · Contributing

先说清楚：这个项目是个人玩出来的，**已知还有 bug**（尤其是真实摄像头下的手势手感、不同机型/光线下的识别阈值、移动端性能）。你遇到问题不是你的错，欢迎直接反馈或动手改。

## 报 Bug

开一个 [Issue](../../issues/new/choose)，选 Bug report，麻烦带上这些：

| 需要的信息 | 怎么拿 |
| --- | --- |
| 浏览器 + 版本 | Edge/Chrome 地址栏输 `edge://version` 或 `chrome://version` |
| 操作系统 / 设备 | Windows 11 / macOS / Android 等，是否外接摄像头 |
| 哪个手势 / 哪个操作 | 例如「✌ 比耶换形态无反应」「食指画到一半断线」 |
| 期望 vs 实际 | 一句话说清 |
| 截图或录屏 | 能录最好，`e` 存图也能当证据 |
| 控制台报错 | `F12` → Console，把红色报错贴上来 |

> 涉及摄像头的问题，先确认你是用 `https://` 或 `http://127.0.0.1` 打开的——`file://` 下浏览器会直接禁用摄像头，这不是 bug。

## 提 PR

1. Fork 本仓库，从 `main` 拉一个分支：`git checkout -b fix/gesture-pinch`；
2. 改完本地跑一遍：`node --check`（把 `index.html` 里 `<script type="module">` 抽出来校验）+ 浏览器实测；
3. 提交信息用一句话说清改了什么，例如 `fix: 捏合与握拳误判，调整 thumbAway 阈值`；
4. 开 PR，描述里写：改动点、验证方式、影响范围（手势/视觉/性能）。

### 代码约定

- 保持**单文件**：所有逻辑都在 `index.html` 里，外部依赖只允许 CDN（Three.js / MediaPipe / 字体），不要引入图片素材；
- 新增形态：在 `shapePoint(name, i, out, p)` 里加分支，并在 `SHAPE_ORDER` / `SHAPE_LABEL` 注册；
- 新增手势：改 `analyze()` 的判据，**必须**用真实样本回归（见 `TESTING.md` 第 4 节的方法），别只凭感觉调阈值；
- 涉及画笔改动的，请顺带更新 `TESTING.md` 的第 5 节人工复测项。

### 提交前自检

- [ ] `node --check` 通过
- [ ] 桌面浏览器实际打开过，树/形态/画笔都正常
- [ ] 没有把调试用的 `console.log`、临时参数留在代码里
- [ ] 截图或动图放进了 PR 描述

## 想加东西但不知道从哪下手

这些是欢迎的方向：

- 新形态（雪人、铃铛、麋鹿、年份数字）
- 新的笔刷质感（火焰、霜花、彗尾）
- 手势：抓取旋转、双手捏合缩放、手掌推拉镜头
- 移动端适配与性能优化
- i18n（英文 README 已部分覆盖，可以补完整）

## 行为约定

友善、就事论事。不接受人身攻击、广告、与项目无关的内容。维护者有权关闭不符合上述约定的 Issue/PR。
